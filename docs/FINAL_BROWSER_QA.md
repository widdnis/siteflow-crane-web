## STEP 6A 마감 — 출력 파일명 및 제목 복원
1. 한글·공백 포함 JSON을 로드 → PNG 저장: {JSON stem}_Layout_{YYYYMMDD_HHMMSS}.png, 로컬 버튼 클릭 시각·2400×1800 확인.
2. PDF 저장 / 인쇄 → PDF 저장 제안: {JSON stem}_Report_{YYYYMMDD_HHMMSS}.pdf. document.title은 .pdf를 제외한 제안 이름이며 브라우저가 확장자를 붙이도록 한다. 브라우저 설정에 따라 실제 저장 이름은 달라질 수 있음.
3. 인쇄 완료·취소 → 탭 제목이 기존 제목으로 복원. 반복 인쇄 시 새 클릭 시각 사용. 인쇄 요청 중 탭 이동 후에도 기존 제목 복원.
4. 새 JSON 성공 → 새 파일명 기준. URL은 마지막 JSON 경로 이름 사용, query/hash 제외. 추출 불가 시 siteflow. 실패·취소 입력은 기존 파일명 기준 유지.
5. UI는 PNG 저장 / PDF 저장 / 인쇄로 정리. missing/null·GH 오류·DEMO·안전성 미검증 안내 유지. 차량·크레인·카메라 상태 보존은 10번 체크 지속.
증거: 실제 다운로드 이름, 클릭 시각, 인쇄 전후 브라우저 탭 제목, PDF 제안/실제 파일명 및 Console 오류.
자동 검증은 API 모의 환경이며 실제 브라우저의 PDF 제안·인쇄 취소·PNG 다운로드는 사용자 확인 대기.


## STEP 6B 사용자 승인 및 배포 전 QA
사용자가 로컬 실제 브라우저 1차 8/8, 2차 정상 5개 및 차량·크레인 상태 보존 추가 확인, 최종 보완 4/4 정상(상태 보존·PNG 파일명·PDF 제안 파일명·UI 문구)을 보고하고 배포를 승인했습니다.
앞선 연결 불가/미검증 기록은 당시 CLI 검증 범위에 대한 이력입니다. 배포된 공개 URL에서의 조작은 배포 후 별도 확인하며, HTTP·정적 파일 검증과 실제 브라우저 조작을 구분합니다.
